### 🤖 **PlayerVec** — [View Repo](https://github.com/ARasugit20/PlayerVec)
ML-powered player embedding system for sports analytics

**What it does:**
- PyTorch autoencoder compressing World Cup player stats into 32-dim embeddings
- Unsupervised clustering of players by playing style
- High-press midfielders, playmakers, and strikers cluster naturally
- **No position labels needed** — pure representation learning

**Tech Stack:** Python • PyTorch • Unsupervised Learning
